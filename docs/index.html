Donne-lui une image.

Un bot Minecraft qui bâtit en jeu à partir d'une photo, d'un modèle 3D ou d'un simple texte. L'IA imagine, la mécanique garantit que ça tienne debout.

Les commandes

Ce que tu peux construire

Tape une commande dans le chat, envoie ton fichier, confirme avec !go.

!photo

Depuis une photo

Un bâtiment interprété et habitable : entrée, étages, toit, déco intérieure.

!diorama

Copie conforme

Un paysage ou un modèle 3D posé sur un relief naturel avec sous-sol.

!statue

Statue voxel

Un personnage 3D voxelisé sur socle, palette de couleurs vives.

!portrait

Fresque pixel-art

Une image transformée en fresque murale d'un bloc d'épaisseur, avec cadre.

!schema

Depuis des schemas

Un bâtiment fidèle inspiré de schemas réels du même style (bascule sur !photo si aucun n'est dispo).

!build <texte>

Depuis une idée

Le bot cherche une image sur le web, la choisit, puis construit.

Pour les curieux et les devs

Sous le capot

L'IA propose, la mécanique dispose. Des garde-fous testés, pas des promesses de prompt — ~495 tests.

Gravité et attachements

Suppression des blocs flottants (parcours de support), torches murales orientées, fondations automatiques sur relief.

Audit d'habitabilité

Hauteur sous plafond, entrée dans les murs, escaliers entre étages — mesurés puis réinjectés dans une passe de correction.

Palettes sémantiques

k-means des couleurs → thème de matière choisi par l'IA → nuançage. Jamais de bloc fonctionnel dans un mur.

Sandbox

Tout code généré s'exécute isolé, avec timeout ; blocs validés en liste blanche, coordonnées bornées.

Modèles configurables

Chaque étape (vision, architecture, palette…) pointe vers un modèle Claude défini dans config.json.

Robuste

Voxelisation asynchrone, reconnexion automatique, commandes throttlées, !undo par instantané.
